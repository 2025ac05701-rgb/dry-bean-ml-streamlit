# 🌱 Dry Bean Classification - Machine Learning Streamlit App

## 📌 Project Overview

This project implements a Machine Learning classification system for classifying different varieties of dry beans based on their geometric and shape-related characteristics.

The project includes multiple Machine Learning classification models and provides an interactive Streamlit web application where users can upload test data in CSV format, select a trained model, and view the prediction results and evaluation metrics.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze the Dry Bean dataset.
- Perform data preprocessing and feature scaling.
- Train multiple Machine Learning classification models.
- Compare the performance of different models.
- Evaluate the models using multiple classification metrics.
- Deploy the trained models using Streamlit.
- Provide an easy-to-use interface for making predictions using uploaded test data.

---

## 📊 Dataset

### Dataset Name

**Dry Bean Dataset**

### Dataset Source

The dataset contains images of seven different types of dry beans. Each bean is characterized using geometric and shape-related features extracted from its image.
